# قائمة التحقق قبل الإطلاق — تيوزدية

## 1. قواعد البيانات والمصادقة
- [ ] إنشاء مشروع Supabase **جديد** داخل منطقة بيانات مدروسة وموافقة للالتزامات النظامية.
- [ ] تنفيذ `supabase/migrations/001_initial.sql` والتحقق من كل الجداول والدوال وRLS.
- [ ] ضبط Site URL وRedirect URLs على نطاق Netlify النهائي.
- [ ] ضبط قالب البريد الإلكتروني OTP والمزود الإنتاجي ومعدلات إرسال آمنة.
- [ ] إنشاء حساب المالك ومنحه دور owner يدويًا عبر SQL للمرة الأولى فقط.
- [ ] إنشاء موظف استقبال ومراجع واختبار الفصل بين الصلاحيات.
- [ ] مراجعة صلاحيات Storage لرفع صور الإعلانات فقط من الإدارة.

## 2. الاستضافة وPWA
- [ ] رفع المجلد إلى GitHub/GitLab وربطه بـ Netlify **كمشروع source**.
- [ ] إضافة متغيرات البيئة الخمس كما في README، مع إبقاء سر التذاكر في Functions فقط.
- [ ] نجاح `npm install`، و`npm run check`، و`npm run build`، و`npm run test:static`.
- [ ] ظهور صورة الشعار الصحيحة وتطابق الألوان مع الهوية.
- [ ] عمل روابط الصفحات الداخلية عند تحديث المتصفح (SPA fallback).
- [ ] تثبيت الموقع من Android Chrome، واختبار إضافة الشاشة الرئيسية من iPhone Safari.
- [ ] التأكد أن التذاكر والتسجيل لا تنجح دون اتصال فعلي؛ عدم تقديم نجاح وهمي أو بيانات مخزنة قديمة.

## 3. الحجز والدفع والمراجعة
- [ ] نشر ورشة مجانية تجريبية وطلب حجز من حساب جديد.
- [ ] عدم إصدار تذكرة قبل اعتماد المراجع.
- [ ] تجربة رابط دفع خارجي في بيئة اختبار المزود دون دفع فعلي.
- [ ] إبلاغ العميل بالمرجع يظهر للإدارة بحالة «العميل أبلغ بالدفع» فقط.
- [ ] التحقق من أن الموافقة على المدفوعة ممنوعة حتى يؤكد المراجع مرجع الدفع ومبلغه وعملته في لوحة المزود.
- [ ] تجربة انتهاء حجز مؤقت بعد 30 دقيقة، وتضارب السعة مع بلاغ دفع متأخر.
- [ ] رفض حجز مدفوع متحقق منه يولد قضية استرداد للإدارة.
- [ ] تجربة تصدير XLSX وفتحه في Excel والتحقق من الأرقام والأسماء والحقول.

## 4. QR والحضور والأمان
- [ ] اختبار عرض QR لحجز معتمد فقط.
- [ ] تمكين متصفح موظف الاستقبال من الكاميرا على HTTPS.
- [ ] أول مسح صحيح يسجل حضورًا واحدًا فقط.
- [ ] ثاني مسح على الجهاز نفسه يظهر «تم تسجيل الحضور مسبقًا» دون إضافة حضور.
- [ ] مسحان متزامنان من هاتفين يسجل أحدهما فقط (اختبار قاعدة بيانات فعلي).
- [ ] مسح تذكرة من ورشة ثانية أو ورشة ملغاة يظهر رفضًا.
- [ ] المستخدم غير الموظف لا يستطيع استدعاء `POST /api/checkin` أو دوال الإدارة بنجاح.
- [ ] التوقيع المزور للـ QR يُرفض قبل استدعاء التسجيل.
- [ ] انقطاع الشبكة لا ينتج رسالة حضور ناجح.
- [ ] إعداد النسخ الاحتياطية واختبار استعادتها.

## 5. محتوى وتشغيل وقانون
- [ ] إزالة البيانات التوضيحية أو استبدالها بورش فعلية دقيقة.
- [ ] اعتماد سياسة خصوصية واضحة ونظام لحفظ البيانات والتعامل مع حقوق أصحابها.
- [ ] نشر شروط التسجيل والاسترداد والإلغاء وطرق التواصل.
- [ ] تحديد آلية خدمة العملاء للمدفوعات المتأخرة أو المكررة.
- [ ] تدريب عمرو والفريق على المراجعة قبل الاعتماد ومطابقة الدفع والتعامل مع فشل QR.

**ممنوع اعتبار النظام جاهزًا لاستقبال مدفوعات حقيقية قبل إنهاء جميع عناصر الدفع والأمان والاختبار.**
